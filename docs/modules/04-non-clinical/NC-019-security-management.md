## 1. Purpose

NC-019 gives the security department one console for **gate & visitor control** (using EN-015 passes), **CCTV health/event dashboard** (via EN-021), a formal **security incident register** (theft, violence against staff, trespass, missing patient/child, fire, suspicious object, vehicle incidents) with investigation, evidence and MLC/police linkage, **patrol management** with QR checkpoints, **access-control** zone rules (who may enter ICU/OT/pharmacy/server room/mortuary and when), **key & material outward** registers, and **emergency code announcement** (Code Blue/Red/Pink/Yellow/Orange/Black/Violet/Grey) with muster & drill records. It supplies NABH FMS/PSQ evidence and violence-against-HCW statutory records.

## 2. Users & Jobs-to-be-done

- **Gate guard** (tablet/kiosk at gate; phone for floor guards): validate visitor/bystander passes (scan QR — EN-015), vehicle in/out, material outward pass check against NC-006 issue notes, deny/allow, log observations, alert control room.
- **Control-room operator** (desktop, multi-monitor + CCTV wall): CCTV camera health, incident intake from calls/radio/app, dispatch guards, launch codes & PA/TV banners, track patrols, monitor door-access alarms (forced/held open), infant tag alarms.
- **Security officer**: incident investigation, evidence (CCTV clip request, photos, statements), police/MLC coordination, patrol plans, guard roster/attendance (via NC-030/NC-029), access zone rules & pass approvals, drills, agency SLA.
- **Ward nurse / any staff**: panic/violence alert from IP-003/NC-014 app; report incident; request escort (mortuary, cash movement, VIP).
- **Admin/MS/Quality**: incident trends, drill compliance, code response times, CAPA.

## 3. Core Workflows

### 3.1 Gate & visitor enforcement (with EN-015)

1. Visitor/bystander pass created in EN-015 (per patient, hours, count limits) → **Guard** scans QR at gate/ward entry → System validates (active, within visiting hours, ward not restricted e.g. ICU max 1, isolation → PPE prompt, patient still admitted via IP-001) → allow/deny with reason → count in/out per patient; overstays flagged; blacklist/watch-list check (prior violence/theft) → Event `security.gate.checked`.
2. **Vehicle gate**: number-plate (manual/ANPR via EN-021), purpose, in/out time; ambulance (NC-013) fast-lane; parking allocation (`security.parking`), staff vehicle stickers.
3. **Material outward**: gate pass from NC-006 issue/return/NC-002 asset movement/NC-007 consignment return/NC-016 BMW vehicle → guard verifies items vs pass (scan) → out-time; unmatched item → hold + officer alert → Event `security.material.out`.
4. Body release (IP-017) → gate release check against release register; new-born discharge (IP-011) → mother-baby band match at exit ("Code Pink" prevention).

### 3.2 CCTV dashboard (`security.cctv`, via EN-021)

- Camera inventory (location, zone, NVR, retention days), health (online/offline/recording gap) with facility ticket auto-raise (NC-025/NC-028), event tagging (link incident ↔ camera/time window), clip export request workflow (who/why/approval, hash, watermark, retention extension for MLC/legal — NC-023), privacy zones (no camera in patient care areas beyond policy), access log for footage viewing (DPDP).

### 3.3 Security incident register

1. **Reporter** (guard/staff/nurse/anyone via app or control room) logs incident: category enum(theft/loss, violence_verbal, violence_physical, property_damage, trespass/unauthorised_access, missing_patient/elopement, missing_child/infant, suspicious_object/bomb_threat, fire/smoke, vehicle_accident, crowd/agitation, weapon, substance, cyber_physical (server room), staff_misconduct, VIP/media, other), location, time, persons involved (staff/patient (UHID)/visitor/unknown), description, injuries (→ ER OP-006 & employee injury NC-010), photos → severity (1–4) → **System** notifies control room & officer, auto-suggests police intimation for violence/theft above threshold, MLC creation (TR-008) if injury/crime → Event `security.incident.reported`.
2. **Officer** investigates: assign, timeline, statements (text/voice), CCTV clip link, evidence chain, actions (guard deployment, restrain per policy, police FIR no., insurance claim (NC-002), HR disciplinary (NC-010)), root cause & CAPA (NC-015 incident engine link — one record, two views), closure with approval; **violence-against-HCW** records generate the statutory register and FIR tracker (state Medicare Act) → Event `security.incident.closed`.
3. Missing patient/elopement: triggers Code Yellow procedure (3.6), ward search checklist, exits sealed, description broadcast to guards' phones, police intimation timer.

### 3.4 Patrols & checkpoints (`security.patrol_qr`)

- Patrol routes (checkpoints with QR/NFC tags via EN-013, expected interval, order) per shift → guard scans each checkpoint (phone; offline OK) → missed/late checkpoints alert control room; observations (light off, door open, leak → NC-025 work order); night patrol log; fire-exit obstruction checks; oxygen manifold/DG/transformer area checks (link NC-025).

### 3.5 Access control (`security.access_control`)

- Zones (ICU, OT, NICU, pharmacy narcotics store, blood bank, server room, MRD, cash room, mortuary, radiology hot lab, stores) with allowed roles/departments/time windows; credentials = staff card/biometric (EN-020 controllers: Wiegand/OSDP via vendor API/HTTP), visitor QR temporary access; **door events** (granted/denied/forced/held-open/tailgate) ingested → alarms; access review reports (who entered server room last month); temporary access requests with approval (EN-038); auto-revocation on employee exit (NC-010) or role change (EN-007); anti-passback optional; key register (`security.key_register`): physical key issue/return with signature, master-key custody.

### 3.6 Emergency codes & drills (`security.codes`)

- Code catalogue (configurable; defaults: Blue = cardiac arrest (IP-013 owns clinical response; NC-019 logs & announces), Red = fire, Pink = infant/child abduction, Yellow = missing patient/internal disaster, Orange = hazardous spill/external disaster (MCI with OP-006), Black = bomb threat, Violet = violent person, Grey = security assistance, Green = evacuation) → **Trigger** from control room, ward panic button (IP-003/NC-014), or physical button (EN-042) → announcement: PA (via EN-018 audio/TV banner), push to code team (EN-037 on-call routing), SMS to security/facility (EN-009), lift override/exit lockdown instructions checklist → **response log**: acknowledgements, arrival times, muster/roll-call (fire; NC-029 in-building list), all-clear, debrief → **drills** scheduled per NABH (fire quarterly, code pink annual etc.) with observers' checklist and scores → Event `security.code.activated|cleared`, `security.drill.recorded`.

### 3.7 Guard force & agency

- Guard master (agency, PSARA verification, police verification cert expiry, training NC-027), posts/beats, roster (NC-030), attendance (NC-029 device or supervisor), post-occupancy dashboard (post unmanned alert), agency SLA/penalties (NC-031), weapon/equipment issue register (torch, radio, baton, metal detector), uniform/ID.

## 5. Business Rules & Validations

- Gate allow only for valid pass state and time window; ICU/NICU visitor caps enforced (count in − out < cap); denial requires reason; every deny/hold notifies control room.
- Material outward: every line must match a source document (issue note/asset transfer/return/BMW manifest); mismatch → hold; officer override audited.
- Incident numbering `SEC_INC` per branch/FY; severity 3–4 auto-notify MS/Admin; violence_physical & weapon → mandatory police intimation field within 24 h (statutory) unless MS waives with reason; injuries → OP-006 visit and NC-010 employee injury record link; incidents involving patients also create NC-015 incident record (single source, linked ids).
- CCTV clip export needs purpose + approver (officer + admin for PHI-sensitive areas), watermark, hash; viewing logged (`READ_PHI`-like `READ_CCTV`).
- Access rules: default deny; role/time based; auto-revoke on `hr.employee.exited`/`user.deactivated`; forced-door/held-open > 60 s → alarm; server room/narcotics store events retained 3 years.
- Code activation: cannot be cleared by trigger source alone (control room clears); response time = first arrival − activation; drills flagged `is_drill` and excluded from live KPIs but counted for compliance.
- Patrol: check-ins must be within ± tolerance; sequence out of order flagged; offline scans accepted with device timestamp.
- Guards without valid police verification cannot be rostered to posts (NC-030 warning/hard-stop configurable).

## 7. Domain Events (outbox)

- `security.gate.checked|denied|material.out|vehicle.in|vehicle.out` → EN-015 counters, NC-006/NC-002 (out confirmation), NC-013, NC-011.
- `security.incident.reported|assigned|police_referred|closed` {incident_id, category, severity, is_violence_hcw} → EN-037 (MS/Admin/HR), NC-015 (incident/CAPA), TR-008 (MLC), NC-010 (employee injury/HR case), NC-002 (insurance).

## 13. Non-functional

- Volumes: 2000-bed hospital → 5–8k visitors/day, 1,500 vehicles/day, 300 cameras, 150 controlled doors (~50k door events/day), 100 guards/3 shifts, 20 patrol routes; gate scan response < 300 ms (Redis pass cache); code push fan-out to 200 users < 3 s; alarm feed < 1 s.
- Offline: gate console & guard app queue; codes always require online control room path plus physical PA fallback.
- Retention/legal hold on clips; audit on all exports; DPDP: CCTV notice boards, footage access logging, purpose limitation.
- Devices: rugged tablets at gates, USB scanners, panic buttons; TV/PA.
- i18n; accessibility; printing (statutory registers, drill reports).

## 14. Acceptance Criteria

1. Given a bystander pass valid 08:00–20:00 for ICU (cap 1), when a second bystander scans at 10:00 while the first is inside, then entry is denied with "cap reached" and control room is notified.
2. Given a material outward pass listing 3 items and the guard finds a 4th, then the pass is put on hold, officer alerted, and outward blocked until override with reason.
3. Given a nurse triggers Code Violet from Ward 6 via panic button, then within 3 s security guards' phones show a full-screen alert, PA/TV banner shows the code & location, and control room sees an active-code timer; clearing requires control room action.
4. Given a physical assault on a nurse logged as `violence_physical`, then police-intimation field becomes mandatory with a 24 h timer, MLC (TR-008) link is offered, NC-010 employee injury record and NC-015 incident are created with cross-ids.
5. Given a CCTV clip export request without an approver, then export is not generated; when approved, the file has watermark + SHA-256 and every view is logged.
6. Given a guard misses checkpoint 4 by > 10 min, then control room receives an alert and the patrol run shows missed_count 1.
7. Given an employee exits (NC-010), then all access credentials are revoked within 60 s and the access review report shows revocation time.
8. Given a server-room door forced open, then an alarm reaches control room and IT admin and an incident draft is created.
9. Given a fire drill run with `is_drill=true`, then it does not affect live response KPIs but appears in NABH drill compliance.
10. Given a visitor on the watch-list scans a pass, then the guard sees a discreet alert and control room is notified without displaying reason to the visitor.
11. Given a guard without valid police verification, then NC-030 shows a warning/blocks assignment to sensitive posts per configuration.
